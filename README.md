# Expense Tracker Pro

J'ai besoin de ton aide pour créer une app personnelle me servant à suivre si mes notes de frais me sont remboursées ou non par ma compagnie. La base est de pouvoir importer un fichier pdf qui est le relevé de ma carte AMEX. Je veux que tu puisses identifier toutes mes dépenses AMEX, je dois ensuite pouvoir manuellement ajouter un numéro de note de frais à chaque dépense, cocher si le remboursement est effectué, si il est effectué de manière partielle, de quel montant (et ensuite pouvoir cloturer quand le remboursement est total). Je veux aussi pouvoir exclure des dépenses si elles sont d'ordre personnelles. Je veux aussi que tu me précises quand des dépenses sont effectuées dans une devise différente de l'euro, les frais appliqués et le montant total final en euros. Je veux que les dépenses puissent être filtrées par dates, et qu'une fonction de recherche soit présente. Voici en PJ un exemple de relevé AMEX que je veux pouvoir importer dans l'app.
